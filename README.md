# asadwebdevelopar

Interactive 3D portfolio and client workspace for **Asad Web Developer**, built with React, TypeScript, Tailwind CSS, Three.js, and Supabase.

## Features

- **3D Fractured Obsidian Hero**: Scroll-driven Voronoi plate reveal paired with a responsive developer portrait and opening intro.
- **Interactive About & Proof Cards**: 3D wireframe cube showcase, live theme/motion lab controls, and telemetry proof widgets.
- **3D Night Tunnel Gallery**: Scroll-navigable WebGL corridor showcasing 12 interactive project panels and case-study modals.
- **Orbital Tech Stack Sphere**: Draggable 3D Fibonacci tech sphere with category filters and live FPS meter.
- **Client Login Portal & Contact**: Supabase authentication, live milestone tasks (`todos`), project inquiry form (`contact_messages`), and direct WhatsApp integration.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
